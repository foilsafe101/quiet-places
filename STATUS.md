# Shhh — Project Status

**Last updated:** 2026-04-25

## What it is
Web map identifying locations with no audible anthropogenic sound (no flights, no roads, no rail). Leaflet frontend, flight data from OpenSky Trino, quiet zone overlay computed from flight + road/rail proximity.

- **Repo:** `/Users/markustribus/quiet-places` (local Mac)
- **Live:** https://foilsafe101.github.io/quiet-places/ (GitHub Pages from `/docs`)
- **Audience:** Mark Tribe, SVA faculty NYC, field-recording scouting (Northeast US priority)

## Key files
- `docs/index.html` — Leaflet map, loads `flights_0.json.gz` + `flights_1.json.gz` in parallel, renders via single canvas layer (`FlightCanvas`)
- `docs/quiet_overlay.png` — Web Mercator RGBA overlay (dark blue = quiet), generated by `generate_quiet_overlay.py`
- `docs/flights_0.json.gz` / `docs/flights_1.json.gz` — worker flight data (gzipped to stay under GitHub's 100 MB limit)
- `query_opensky_paths.py` — queries OpenSky Trino, RDP_TOLERANCE=0.1°, 11 regions, `--worker 0` or `--worker 1`
- `generate_quiet_overlay.py` — outputs Web Mercator PNG (1440×1019)
- `run_batches.sh` — continuous 200-slot batches, commits+pushes after each; run as `bash run_batches.sh 0` and `bash run_batches.sh 1` in parallel

## Acoustic thresholds
- Flights audible: 0.29° (~20 mi)
- Roads/rail audible: 0.015° (~1 mi)
- Fully quiet: 1.5° from any noise source

- Removed merged `flights.json` from git (>100 MB GitHub limit); HTML loads worker files directly
- Switched flight rendering from individual `L.polyline` objects to single canvas layer — pan/zoom now instant
- RDP tolerance bumped 0.01° → 0.1°, existing data re-simplified
- Canvas pan/zoom tracking fixed (uses layer points + `L.DomUtil.setPosition`)
- Flights lazy-load on demand (slider starts at 0, loads on first drag) — map opens instantly
- JSON saves now atomic (write to .tmp, rename) — prevents corruption on interrupted writes
- `run_batches.sh` merge step made resilient to corrupt worker files
- Northeast region expanded: lat 38→72°N, lon -82→-20°W (captures high-lat routes + N Atlantic gap)
- Flight lines: semi-transparent thin strokes (`rgba(220,30,30,0.15)`, lineWidth 0.7) for heatmap effect
- Migrated flight data to gzip (`.json.gz`) to stay under GitHub's 100 MB file limit
